# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Vite + React 19 + TypeScript + Tailwind CSS v4 + Lucide React icons + GitHub Raw JSON API

## Users
Türkiye'deki anime severler; minimal, reklamsız, Vercel estetiğinde arama motoru arabirimiyle Türkçe altyazılı anime aramak ve anında izlemek isteyen kullanıcılar.

## Product Purpose
Anime izleme deneyimini Vercel tarzı keskin, simsiyah ve minimalist bir arama motoru konseptinde sunmak; GitHub üzerindeki TurkAnimeTV arşiv JSON verilerinden (animeler.json, info.json, bolumler.json, episode.json) canlı veri çekerek iframe embed player ile kesintisiz izleme sağlamak.

## Positioning
Vercel estetiğinde keskin çizgili, ultra hızlı, arama odaklı siber-minimalist Türkçe anime arama ve izleme platformu.

## Operating Context
Masaüstü ve mobil ekranlarda `Cmd+K` / `/` kısayolları ile arama yapma, sonuçları liste halinde inceleme, anime detaylarını ve bölümlerini iframe video player üzerinden izleme ve kaldığı yeri `localStorage` ile kaydetme.

## Capabilities and Constraints
- Vercel Tarzı Keskin Dark Tema (Obsidian Black #000000, 1px Neutral Borders, Monospace Accent Badges)
- Ekran Ortası Arama Motoru (Center Search Box) ve `Cmd+K` / `/` klavye kısayolu
- TurkAnimeTV GitHub JSON API Entegrasyonu (animeler.json, info.json, bolumler.json, episode.json)
- Dynamic iframe Embed Player (MAIL, OK.RU, SENDVID, MP4UPLOAD, UQLOAD, VUDEA alternatifleri)
- LocalStorage tabanlı "En Son İzlenenler" (Recently Watched) ve Favoriler
- %100 Türkçe Arayüz

## Brand Commitments
- İsim: TurkAnimeMirror (Vercel Anime Search Engine)
- Renkler: Pitch Black (#000000), Dark Panel (#0a0a0a), Border (#262626), White Accent (#ffffff), Subtle Cyan/Violet (#0070f3)
- Dil: %100 Türkçe

## Evidence on Hand
TurkAnimeTV GitHub Arşiv JSON API (`https://raw.githubusercontent.com/agnogad/TurkAnimeTV_Arsiv_json/main/animeler/`)

## Product Principles
1. Vercel Hassasiyeti & Keskin Çizgiler: Gereksiz süslemeler yerine yüksek kontrastlı, 1px kenarlıklı, tipografik netlik.
2. Arama Motoru Hızı: Arama kutusu ekranın merkezinde; yazıldığı an sonuçlar anında sıralanmalı.
3. Canlı Veri & Güvenilir Embed Oynatıcı: GitHub JSON API'sinden anlık veri çekilmeli ve embed iframe'ler akıcı bir şekilde sunulmalı.
